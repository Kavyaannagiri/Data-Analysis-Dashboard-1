# E-Commerce Sales Analysis Dashboard
## Project Objective
The objective of this project is to analyze e-commerce sales data and build an interactive Power BI dashboard to understand sales performance, profitability, products, regions, and sales trends.
## Dataset used
- <a href="https://github.com/Kavyaannagiri/Data-Analysis-Dashboard-1/blob/main/E-Commerce%20Sales%20Data%20Analysis%20Data%20Set.csv">Dataset</a>
## Questions & KPIs
- What is the total sales and total profit?
- Which category generates the highest sales and profit?
- Which region has the highest sales?
- What are the sales trends over time?
- Which products contribute the most to sales?
- What is the average sales value?

## Process
* Imported and cleaned the raw e-commerce dataset using Power Query.
* Transformed the data, created relationships, and developed DAX measures.
* Built an interactive Power BI dashboard to analyze sales, profit, products, categories, regions, and trends.
